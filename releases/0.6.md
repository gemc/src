# GEMC Release 0.6

Upcoming in the next release. Changes since `0.5`.

This version includes:

- Logging and GUI translations with automatic language selection and English fallback.

<br/>

# Release notes

- Logging can use translated message catalogs, detecting the user's language automatically and accepting
  a command-line or YAML override. Missing translations fall back to English without changing numeric
  formatting or fatal exit codes. Project-language catalogs use the shared Claude/Codex translation workflow.
- GUI controls, tooltips, geometry descriptions, analyzer messages, and SVG captions support Italian,
  Japanese, French, and Chinese. GUI language follows the logging setting; Qt catalogs translate standard
  dialogs when installed. Restart GEMC to change the language.
- Unknown command-line options and switches now fail with a clear error and a "Did you mean -X?" suggestion
  instead of being silently ignored. Typos are reported even alongside early-exit flags such as `-v` or
  `help`, and GNU-style long forms (`--language=fr`) are accepted as aliases of the single-dash form.
- Python API changes are documented in the
  [pygemc release notes](https://github.com/gemc/pygemc/tree/main/releases).
- Option search now includes detailed help, schema keys and descriptions, and default values, so
  `gemc search driver` and `gemc search OGL` find `g4view`.
- The volumes tree supports multiple selection with Cmd/Ctrl-click and Shift-click. Space hides the selected
  group if any selected row is visible, or shows it when all are hidden, preserving checkbox child propagation.
- Added an XR Server button under Display > Utilities to open the XR driver and export one event with tracks.

## Compatibility notes

- `GLogger` methods now accept a complete message template followed by its parameter values.
  Update concatenating calls in external plugins and rebuild them against matching GEMC headers.
  Standalone consumers also link the new `glogging` library; plugins must rebuild for the updated logger layout.
  Dynamic or already-formatted strings must be passed as values to preserve literal percent signs:

  ```cpp
  // Before: log->info(0, "Starting run ", runNumber, ".");
  log->info(0, "Starting run %1.", runNumber);
  log->warning("%1", diagnosticText);
  ```

## Detailed list of changes and fixes

- Enabled the volumes GUI's "Draw Logical Overlap within <volumename>" action in a separate viewer,
  using OpenGL for ToolsSG viewers to avoid its logical-volume rendering crash and restoring focus afterward.
- Register the Geant4 `Xr` visualization driver when its installed library is omitted by `geant4-config`;
  refresh dependency flags on reconfigure after Geant4 is rebuilt in place.
- Mark Geant4 core dependency headers as system includes, eliminating repeated Homebrew Qt
  `#include_next` warnings during compilation while retaining project warning checks.
- Delegate Python environment creation and dependency installation to the pygemc subproject,
  removing the duplicate GEMC installer and using pygemc's exported build interpreter.
- Fixed field-example startup crashes introduced by logging translations: field plugins now exclude the
  host registry implementation, preventing duplicated Geant4 geometry state from corrupting worker data.
- Made generated logging catalog references independent of source line numbers, preventing CI freshness
  failures when unrelated edits shift logging calls; extraction errors still report exact source lines.
- Fixed GTree compilation on Qt configurations that do not indirectly include `QCoreApplication`.
- Added translated startup/version banner labels, keeping metadata as parameter values. The early version
  action accepts the language override in either argument order and retains automatic selection and fallback.
- Hardened command-line parsing: every token is validated before any early-exit flag acts, so a typo is no
  longer swallowed by `-v`/`-h`/`help`/`search`. Unknown names emit a case-insensitive Levenshtein-based
  `Did you mean -X?` suggestion (new `gutilities::closestMatch`) and a pointer to `-h`, exiting with the
  existing `EC__NOOPTIONFOUND` (101). A leading `--` is normalized to `-` so long forms resolve and error
  messages no longer carry a spurious dash.

- Added `%1` through `%99` parameters, literal percent escaping, and malformed-template validation
  to the canonical `GLogger` methods. The transitional `*Template()` names remain forwarding aliases.
- Migrated framework, example, and test logging calls to complete messages, preserving English output,
  verbosity filtering, standardized headers, and exit codes. Dynamic diagnostics remain parameter data.
- Added generated English logging catalogs with source references and a reusable C++ template extractor.
  Catalog validation rejects duplicate/unknown keys and changed placeholder positions.
- Added immutable runtime catalogs, automatic locale selection, and a `language` scalar override. Catalog
  search supports framework/plugin installations and build trees, with English fallback and no file I/O per message.
- Integrated runtime catalogs into the existing shared translation manifest and weekday cron job. Agent
  batches receive Codex review and local format checks, with atomic checkpoints and source-commit provenance.
- Added context-aware GUI catalogs to the shared translation workflow with reviewed resumable batches and
  source-commit tracking. Serialized state writers to protect progress during concurrent manual/cron runs.
- Embedded compiled GUI catalogs and installed QMs, preserving translations after executable relocation.
- Kept projection/culling commands and event counters independent of translated labels; allowed the GUI
  window to grow for translated text and resized SVG captions to fit their buttons.
